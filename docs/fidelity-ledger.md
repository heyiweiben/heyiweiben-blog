# 参考图保真记录

本记录对应锁定参考图 `references/locked/v1/` 与三档最终截图 `qa/`。实现目标是复刻已确认的视觉世界与阅读节奏；文字、导航和正文始终由代码渲染，不烘进图片。

## 首页山水 Hero

<!-- identity-section:hero status=pass -->

- 保留参考图的左侧标题安全区、右下山体展开方向、雾米白基底和“问题之下 → 山水”的焦点顺序。
- 远山、中景、近景分别由 WebP 图层承载，并以轻微不同的 CSS 位移形成滚动景深；开启减少动态效果时切换为静态合成图。
- 实现比参考图略有更深的景深和饱和度，但没有改变构图拓扑，也没有重新引入球体、工程线或科技背景。

## 首页文章区

<!-- identity-section:home-writing status=pass -->

- 保留三篇文章、第一篇主导、其余两篇收敛的编辑式层级，文章入口只出现一次。
- 相比参考图，首篇标题更强，信息顺序采用“标题—摘要—日期”；这是为了让真实标题长度和手机换行保持稳定的有意调整。
- 未采用卡片墙、分类入口或重复文章导航。

## 文章归档

<!-- identity-section:archive status=pass -->

- 保留年份、轻量筛选与时间索引语义；深青文字、夕照橙活动线和雾感背景与统一视觉系统一致。
- 桌面端使用年份侧栏与横向条目，较参考图的纵向编辑列表更紧凑；移动端重新排列为日期/分类在上、标题在下，而不是缩小桌面布局。
- 这一差异属于真实内容密度适配，不改变归档的导航目的。

## 长文阅读页

<!-- identity-section:article status=pass -->

- 保留山形题头、标题、导语和窄正文列；正文使用本地思源宋体替代系统不稳定字体。
- 第一段从 Markdown 正文提升为导语，同时仅从正文 HTML 中移除该第一段，原文其余段落完整保留，没有改写作者观点。
- 日期移到标题上方、桌面标题更大；正文行宽约 `44rem`，手机端独立调整字号与行距。

## 关于页

<!-- identity-section:about status=pass -->

- 保留山谷包围文字的开放式构图和原有关于文字，不包装个人履历，不使用半透明通用卡片。
- 桌面五栏主题在移动端改为单列分组，以优先保证完整信息和触控阅读；编辑感略有收敛，但语义和视觉世界不变。

## 全局实现取舍

- 锁定参考图继续保存为 PNG；线上交付的山水层全部使用由同一母图生成的 WebP，降低首屏资源体积。
- 原素材并非真实透明通道，因此采用 `mix-blend-mode`、遮罩和雾层完成融合，不伪造透明 PNG。
- 本地字体采用 `Noto Sans SC Variable` 与 `Noto Serif SC Variable`，分别承担界面/标题和长文正文，避免国内访问依赖外部字体服务。
- React Router 构建保留 `ssr: true` 以生成服务端构建中间产物并规避 Windows 清理异常；Cloudflare 仍只部署完全静态的 `build/client`。
- 所有草稿在内容生成阶段排除，参考图中的示意文案没有覆盖真实文章内容。
