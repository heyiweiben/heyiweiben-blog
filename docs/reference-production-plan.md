# 何以为本当代山水参考图生产计划

## 已确认 brief

- 站点形态：安静、现代、有东方气质的独立写作刊物。
- 核心任务：形成有辨识度的首页，并提供清楚舒适的文章阅读体验。
- 内容边界：只使用现有文章、现有关于页以及已确认首页文案；不创造履历、指标、项目或身份主张。
- 首页文案：`问题之下`；`在技术、商业与生活之间。`
- 页面集合：首页 Hero、首页文章区、文章归档、长文阅读页、关于页。

## STYLE_FINGERPRINT

- 配色角色：雾米白 `#F3F0E8`；深青墨 `#173D3A`；山林绿 `#6D9B88`；暮色蓝 `#7186A6`；夕照橙 `#DE765F`。
- 字体角色：现代稳定的中文无衬线用于 wordmark、标题、导航和标签；清晰中文衬线用于长文正文。避免异形字、书法字和过度古典气质。
- 全局 chrome：左侧代码文字 wordmark“何以为本”；右侧单一“索引”；无胶囊按钮、无卡片式导航、无额外 CTA。
- 几何语言：开放式版面、细分隔线、近乎无圆角、无厚重投影；靠尺度、裁切、对齐和留白建立层级。
- 图像语言：当代数字绘画山水，半写实山形、低饱和青绿与暮蓝、柔和薄雾、克制暖色天光；图像与版面互相渗透，不是右侧贴图。
- 材质：细微纸感与空气颗粒，只作为全站共享 fingerprint；不使用发光球、工程线、节点、赛博黑底、随机渐变、装饰图表或卡片墙。
- 密度与节奏：低密度、编辑式、rich-to-calm；首页 Hero 丰富，文章区和内页逐步安静。
- 动效暗示：山体景深、雾层漂移和低频环境光；不暗示高速或交互型科技动画。
- 画布：横向网站 section 截图，目标构图适配 `1672×941`，并为 `2200×1200` 与 `390×844` 预留裁切和重排空间。

## Section render contracts

### 01 / 首页 Hero — C1 integrated-scene

- 三秒信息：这是“何以为本”的写作网站，主题是问题与思考。
- 主焦点：代码渲染的大标题“问题之下”；第二焦点是融入整体构图的彩色山水。
- 阅读路径：wordmark → 主标题 → 副标题 → 向下进入文章。
- 作者性动作：雾中山势从页面下缘和右侧共同生长，让留白成为正文出现的空间。
- 代码区域：wordmark、索引、标题、副标题及辅助访问控制。
- 图像区域：连续山水环境；文字安全区位于左中部，任何山脊和高对比光源不得侵入。
- 留白职责：聚焦标题，并为不同宽度裁切提供 runway。
- 禁止：左右割裂、孤立右图、线球网络、额外按钮、英文标签、文字烘进最终素材。

### 02 / 首页文章区 — C0 code-only + global material

- 三秒信息：这里有三篇可阅读文章。
- 主焦点：第一篇置顶文章标题；其余两篇按清晰顺序下降。
- 阅读路径：区名 → 第一篇 → 第二、三篇 → 查看全部文章。
- 作者性动作：文章行像山势的三个水平层次，由日期、标题和摘要形成错落但稳定的编辑节奏。
- 代码区域：全部文章信息和链接。
- 图像区域：仅复用极淡的全站雾色/纸感，不生成 section 专属主体图。
- 禁止：三张卡片、分类墙、重复入口、缩略图拼贴、无效大面积空白。

### 03 / 文章归档 — C0 code-only + global material

- 三秒信息：按时间浏览全部已发布文章，并可轻量筛选。
- 主焦点：年份和文章标题序列。
- 阅读路径：页名 → 年份 → 条目 → 分类/标签筛选。
- 作者性动作：年份像远山层级，文章标题沿同一基线形成编辑索引。
- 代码区域：全部标题、日期、摘要、分类、标签与筛选控件。
- 图像区域：页首只保留静态薄雾与低对比局部山形。
- 禁止：侧栏仪表盘、卡片网格、搜索框、分类主导航。

### 04 / 长文阅读 — C0 code-only + global material

- 三秒信息：一篇可沉浸阅读的中文长文。
- 主焦点：文章标题；正文随后自然进入窄列阅读。
- 阅读路径：标题 → 日期/字数 → 导语/正文。
- 作者性动作：页首山形只作为标题下沉的静态余韵，正文区域完全平静。
- 代码区域：所有文章文本、链接、标题、引用、代码块和元数据。
- 图像区域：共享静态山水薄片或雾感页首，不持续运动。
- 禁止：悬浮目录、阅读进度线、社交按钮墙、正文背景动画。

### 05 / 关于页 — C1 integrated-scene

- 三秒信息：这是何以为本长期记录真实问题的写作说明。
- 主焦点：现有关于页首段与“不追热点，不讨好算法，只做长期积累”。
- 阅读路径：页名 → 核心说明 → 五类写作内容 → 联系方式。
- 作者性动作：文字像沿雾谷展开的短篇序言，山水只包围而不插入正文。
- 代码区域：所有关于文字和邮箱。
- 图像区域：低对比、静态连续的山谷与雾面。
- 禁止：头像占位、虚构个人资料、项目履历、联系表单、卡片列表。

## 审查规则

- 每个 section 只生成一张独立横向参考图，不生成长网页拼图。
- Hero 先作为 anchor；后续参考图沿用完全相同的色彩、字体角色、材质和 chrome。
- 每张图只有一个主焦点，最多两个辅助焦点。
- 文字与导航在最终实现中始终由代码渲染；参考图中的文字只用于表达层级和位置。
- 展示前完成视觉意义、一致性、单调性和可复刻性四向审查；失败画面内部重生成，不提交用户确认。
