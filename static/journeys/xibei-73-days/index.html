The Journey

我们把秋天，走成了一条路

路线不是一条预先画死的线。天气、道路、孩子的状态和一家人的体力，一起决定了我们第二天去哪里。

01

先把家留在身后

9/12—9/20 · 重庆至乌鲁木齐
重庆 → 陇南 → 兰州 → 永登 → 张掖 → 哈密 → 巴里坤 → 乌鲁木齐

出发第一天就开到深夜。我们一路做饭、补能、保养车辆，经河西走廊向西。进疆后没有照原计划直奔吐鲁番，而是临时翻过东天山去了巴里坤。真正的长途旅行，从接受变化开始。

“计划给方向，日子自己决定速度。”

02

赶上北疆最好的秋天

9/21—10/2 · 可可托海至独山子
五彩湾 → 可可托海 → 阿禾公路 → 禾木 → 喀纳斯 → 布尔津 → 五彩滩 → 乌尔禾 → 独山子

额尔齐斯河谷已经入秋，阿禾公路把我们带进禾木。到了喀纳斯，我们放弃观鱼台和白哈巴，把体力留给孩子，也留给三湾的第二次徒步。少看两个“必打卡”，并没有让旅程少一点。

“我们不是赶到风景里，而是一起走进风景里。”

03

在封路前，走完整条独库

10/3—10/5 · 独山子至库车
独山子 → 乔尔玛 → 那拉提 → 巴音布鲁克 → 铁力买提达坂 → 库车

雪、冰雹、大雾和临时管制轮番出现。我们跟着现场路况一点点向前，在巴音布鲁克看九曲十八弯，第二天翻过铁力买提达坂，从北疆走进南疆。三天不长，却像穿过了几个季节。

“有些路的意义，就在它随时可能关闭。”

旅行到后来，景点只是坐标。真正留下来的，是菜市场、停车场、服务区，是一家人怎么吃饭、洗衣、睡觉，怎么在陌生地方继续过自己的日子。

—— 南疆慢生活，2026年10月
04

南疆不是经过，是生活

10/6—10/25 · 库车至托克逊
库车 → 温宿 → 喀什 → 塔县 → 莎车 → 泽普 → 叶城 → 和田 → 民丰 → 塔中 → 轮台 → 库尔勒

我们在喀什看古城，也沿中巴友谊路上到帕米尔；在莎车听十二木卡姆，在和田连续住了三天。后来穿越塔克拉玛干沙漠公路，长路、日照、饮水和电量都必须提前安排。南疆最难忘的，不只是辽阔，还有生活本身。

“停下来，才看见一个地方真正的样子。”

05

从火焰山，走回河西走廊

10/26—11/8 · 吐鲁番至中卫
吐鲁番 → 鄯善 → 哈密 → 敦煌 → 玉门关 → 瓜州 → 嘉峪关 → 肃南 → 张掖 → 武威 → 中卫

火焰山、库木塔格沙漠、莫高窟、玉门关、嘉峪关……课本里的名字开始一一出现在车窗外。施工和过境管控让旧路线几次作废，我们就按真实可走的路继续。历史并不只在景区里，也在沿途每一段地名里。

“从敦煌出来以后，风里仿佛都有时间。”

06

最后一段，是回家的路

11/9—11/23 · 中卫至重庆
沙坡头 → 银川 → 包头 → 库布齐 → 鄂尔多斯 → 延安 → 黄帝陵 → 西安 → 秦岭 → 宁陕 → 重庆

在包头停了六天，把身体和生活都重新收拾好。之后沿内蒙古、陕北一路南下，走过延安、黄帝陵和西安，再翻越秦岭。11月23日22:26，我们回到重庆。进门后做了一顿晚饭，73天就这样落回日常。

“原来旅程的终点，不是最后一个景点，而是家里的那顿饭。”

73天里，有雪山、沙漠和胡杨，也有补能、做饭、洗衣和临时改道。宏大的风景最后都变成了很小的事情：一家人在一起，知道什么时候继续，什么时候停下，什么时候回家。
